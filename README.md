# Stage 2 Scanner (hosted)
1. Create a new GitHub repo, upload these files (keep the .github/workflows folder).
2. Settings > Pages > Source: **GitHub Actions**.
3. Actions tab > "Stage 2 scan" > **Run workflow**. Your page URL appears in the run summary.
It then re-runs automatically every weekday at 16:00 IST. Bookmark the Pages URL.
If niftyindices.com blocks the runner, add midcap.csv / smallcap.csv (with a Symbol column) to the repo root.
